# i18n-request

Horizontal review requests are made via issues in this repo, and tracked by our [radar](https://github.com/orgs/w3c/projects/91/views/1).
W3C Working Groups are required to do horizontal review as part of the Process.
The I18N Working Group also supports requests from Web and internationalization related standards groups,
notably 
WHATWG, 
Unicode, 
IETF, 
and ECMA TC39 TG2 (JavaScript Intl).

Quoting the [Guide](https://www.w3.org/Guide/documentreview/#how_to_get_horizontal_review):

<div style="border: 1 rem solid gray; padding: 10px; border-radius: 3px;">

Read the [Request a review](https://www.w3.org/International/review-request) page,

then [request a review](https://github.com/w3c/i18n-request/issues/new/choose) in this repo.
