# i18n-request

Horizontal review requests are made via issues in this repo, and tracked by our [radar](https://github.com/orgs/w3c/projects/91/views/1).

Quoting the [Guide](https://www.w3.org/Guide/documentreview/#how_to_get_horizontal_review):

Read the [Request a review](https://www.w3.org/International/review-request) page, 
then work through the [Short Checklist](https://www.w3.org/International/i18n-drafts/techniques/shortchecklist), 
then [request a review](https://github.com/w3c/i18n-request/issues/new/choose) in this repo.

Useful Links:
   * [Request a review](https://www.w3.org/International/review-request)
   * [Self-Review Questionnaire](https://www.w3.org/International/i18n-drafts/techniques/shortchecklist)

   * The [Review Radar](https://github.com/w3c/i18n-request/projects/1) shows the status of open reviews
   * [Horizontal Review tracker](https://w3c.github.io/horizontal-issue-tracker/index#)
